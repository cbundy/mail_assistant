iCloud Mail Assistant — FINAL

1. Распакуйте содержимое архива в:
   C:\Users\HP\icloud-mail-agent
2. Разрешите Windows заменить app.py, requirements.txt и START.bat.
3. Папку .venv удалять не нужно.
4. Запустите START.bat.

Безопасность:
- основной пароль Apple не нужен;
- используется app-specific password;
- пароль не сохраняется в файл;
- удаления перемещают письма в Корзину;
- перед удалением показывается точный предварительный список;
- массовые действия требуют отдельного подтверждения.
